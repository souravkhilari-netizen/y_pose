# Yoga Pose Detection Frontend

A React + Vite application for detecting and practicing yoga poses using MediaPipe vision tasks.

## Features

- Real-time camera preview
- Yoga pose detection (Mountain Pose, Tree Pose)
- Live feedback on pose accuracy
- Interactive pose selection and practice interface

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Technologies

- React 18
- Vite
- MediaPipe Tasks Vision
- React Router DOM

## Deployment

This app is configured for Vercel deployment with the included `vercel.json` configuration.
